## 🌟 Overview

**LataTea** is a full-stack brand showcase and product catalog engineered with React, TypeScript, and Vite. It includes dedicated pages for products, manufacturing process, company story, contact workflows, and an administrative content view.

---

## 🚀 Live Deployment

* **Production URL:** [https://latatea.vercel.app](https://latatea.vercel.app)
* **Hosting:** Vercel Edge Network ($0.00 Free Tier)

## 🏗️ Architecture

```bash
LataTea/
├── src/                   # React + TypeScript pages & components
├── server/                # Optional backend CMS service
├── public/                # Static brand assets
├── vercel.json            # SPA routing & Vercel build config
└── vite.config.ts         # Vite bundler configuration
```

## 💻 Quick Start

```bash
# Clone the repository
git clone https://github.com/PTejasKr/LataTea.git
cd LataTea

# Install dependencies & run dev server
npm install
npm run dev

# Build for production
npm run build
```
